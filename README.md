# **Telapoka 2** 🪳✨  
*The Ultimate Bangladeshi Flappy Bird Experience*

**🚀 No Live Demo? No Problem!**  
This meme-packed game runs 100% in your browser - just download and open the HTML file!

## **📥 How to Play Locally**
1. **Download the game**:
   - Click `Code` → `Download ZIP`
   - Or clone with Git:
     ```bash
     git clone https://github.com/yourusername/telapoka2.git
     ```

2. **Run the game**:
   - Unzip the folder
   - Open `telapoka2.html` in any browser (Chrome/Firefox recommended)
   - No installation needed!

## **🕹️ Game Features**
- Play as 5 iconic Bangladeshi characters
- Authentic sounds and chaotic obstacles
- Progressive difficulty (gets wild after 15 points!)
- Mobile touch support (try on your phone!)

## **🛠️ Tech Inside**
```plaintext
HTML5 Canvas | Vanilla JavaScript 
CSS Animations | Web Audio API
Zero dependencies - runs anywhere!
```

## **⚠️ Troubleshooting**
If the game doesn't load:
1. Make sure you're opening the HTML file directly
2. Check browser console for errors (F12 → Console)
3. Disable ad-blockers just in case

**Pro Tip**: For best performance, use Chrome and refresh if sounds glitch!
